# tribunal

*Site-authored. This term was written for invisibleships.com to explain the work; it is not extracted from the source document series, and it carries no source-document id for that reason. Terms drawn from the primary record are in `glossary/` and do carry one.*


A court or other body set up to hear a case and decide it. The word is also used more loosely for anything that passes judgment, as in “the tribunal of public opinion.”

The [Nuremberg Code](/glossary/nuremberg-code) came out of one: the American military tribunal that heard the Doctors' Trial and issued the code in its judgment in 1947. A tribunal set up for a single conflict or set of crimes differs from a permanent court such as the [International Criminal Court](/glossary/international-criminal-court).

Related terms: [International Criminal Court](/glossary/international-criminal-court), [Nuremberg Code](/glossary/nuremberg-code)
