# Microsoft Azure Govt Cloud Gets FedRAMP High ATO From VA

*ExecutiveBiz. Original: <https://www.executivebiz.com/articles/microsoft-azure-govt-cloud-gets-fedramp-high-ato-from-va>*

The Department of Veterans Affairs granted Microsoft's Azure Government cloud a FedRAMP High authority to operate on 16 March 2017, ExecutiveBiz reports. The authorization means the platform meets the security standard for sensitive VA workloads, including personal and health information, and lets the department use Microsoft services such as Azure SQL Database and Power BI.
